# AirBlast
Python Shell Script Automating Aircrack wirless networks DDOS Attack.

# How To Use 
Open a Terminal:

Navagiate to the Path of the script (cd /home/newuser/Desktop/airblast.py).

Make sure you have Python installed (python3 --version).
Make sure the aircrack-ng suite (which includes airmon-ng and aireplay-ng) and wireless-tools (which includes iwconfig) are installed on your system. If not you  need to install them 

Run:

sudo python3 airblast.py.

 If The App Fails to Stop Monitor Mode 

sudo service network-manager restart.
